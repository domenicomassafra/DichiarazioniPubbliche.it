# Image prompt — Direction A: Editorial Evidence

Generate a high-fidelity desktop web product mockup, 16:10 landscape, for an Italian
fact-checking platform called **Dichiarazioni Pubbliche**. This is a public consumer homepage, not an
admin dashboard and not a newspaper clone.

Visual direction: premium contemporary editorial design, exceptionally clean, calm,
trustworthy, generous whitespace, strong modern typography, subtle rules and cards,
mostly neutral black/white/warm-gray surfaces with one restrained brand accent. Avoid
courtroom, law-firm, government-portal, parchment, stamp, gavel, scales-of-justice,
newspaper-front-page and generic AI-chat aesthetics.

Top navigation: Dichiarazioni Pubbliche wordmark; Fact-check; Esplora; Persone; Temi; Metodo; search
icon. No political party colors.

Hero should make the product instantly obvious:

headline: "Verifica ciò che viene detto."

supporting line: "Fact-checking di dichiarazioni, video, podcast e articoli. Con fonti
verificabili e memoria nel tempo."

Below the hero, show a prominent elegant search field labelled "Cerca una verifica" and a
secondary subtle action "Proponi una verifica".

Main content: a refined grid/list of recent fact-check cards. Each card prioritizes the
original checked statement in large quotation typography, then a small origin/speaker
line, source, date, concise assessment badge, one-sentence finding and a "Vedi le fonti"
affordance. Use nuanced statuses such as "Supportata", "Manca contesto", "Contraddetta",
"Non risolta"; do not show scores, meters, percentages or person rankings.

Add one horizontal section titled "Video e podcast verificati" with a media thumbnail,
duration, several timestamp markers and a count of checked claims. Add one small section
"Dal record" showing a simple two-date statement comparison to hint at longitudinal
memory.

The overall impression should be closer to a world-class independent digital publication
crossed with a precise evidence product: approachable to a normal reader, distinctive,
not bureaucratic, not sensationalist. Ultra-polished product design, realistic spacing,
realistic Italian UI copy, no lorem ipsum.
