# Image prompt — Direction D: Media Timeline / ContentAudit

Generate a high-fidelity public desktop webpage mockup, widescreen 16:10, for **Agli
Atti**, centered on a fully analyzed video or podcast episode. This should be the
signature ContentAudit experience: media + time + claims + evidence.

Visual direction: refined modern editorial/product hybrid, large clean typography,
neutral background, beautiful spacing, subtle brand accent, no legal/court imagery, no
truth meters, no politician scorecards, no generic news-article layout.

Header navigation: Dichiarazioni Pubbliche; Fact-check; Esplora; Persone; Temi; Metodo; search.

Top content header:
- media title and source;
- publication date and duration;
- a small label "Analisi completata";
- concise summary such as "18 affermazioni verificabili · 12 con verifica conclusa · 4
  non risolte · 2 non verificabili". These are content counts, not a person score.

Main layout:

LEFT 55–60%:
- large video/podcast player;
- directly beneath it, an elegant full-width timeline with timestamp markers for checked
  claims;
- marker shapes/states distinguish completed, context-needed and unresolved without
  relying on red/green alone;
- clicking a marker conceptually jumps to that moment.

RIGHT 40–45%:
- synchronized transcript/claim list;
- selected claim card with timestamp and original wording;
- normalized claim below in smaller structured text;
- concise assessment and 2–3 sentence finding;
- evidence cards with source title, publisher/date and "Apri fonte";
- a subtle link "Perché questa valutazione?" exposing methodology/provenance.

At the bottom of the visible screen, show a horizontal section "Nel tempo" containing one
older related statement and one newer statement with a simple comparison connector,
suggesting Dichiarazioni Pubbliche's memory feature.

The page should feel uniquely designed around video/podcast fact-checking, not like an
article with an embedded YouTube player. It should be immediately understandable to a
normal reader and visually strong enough to become the product's signature screenshot.
