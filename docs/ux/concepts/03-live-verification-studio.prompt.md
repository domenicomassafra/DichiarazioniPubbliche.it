# Image prompt — Direction C: Live Verification Studio

Generate a high-fidelity desktop application mockup, widescreen 16:10, for **Dichiarazioni Pubbliche —
Verify Studio**, a private professional workspace that fact-checks video, podcasts,
articles, URLs, uploaded files and pasted text.

This is the dense operator surface of the same brand as a calm public fact-checking site.
It must feel premium and modern but not like a developer IDE, SOC dashboard, terminal or
generic AI chat product. Neutral light or soft dark surfaces are acceptable; use one
restrained brand accent and semantic states with text + icon, never color alone.

Top bar: Dichiarazioni Pubbliche / Studio; "Nuova verifica"; In corso; Coda; Record; Revisioni. Show a
compact job title based on a podcast/video URL and a visible private-workspace indicator.

Create a three-column live workspace:

LEFT — media + transcript:
- embedded video/podcast player at top;
- timeline with small claim markers;
- timestamped live transcript below;
- selected sentence highlighted, with speaker label only when provenance exists.

CENTER — detected claims:
- vertical queue of claim cards extracted from the transcript;
- each card shows timestamp, original wording and compact normalized checkable claim;
- realistic pipeline states such as "Da verificare", "Cerco fonti", "Fonti acquisite",
  "Verifica in corso", "Manca contesto", "Pronta per revisione";
- no final publication state merely because analysis completed.

RIGHT — evidence + review:
- selected claim detail;
- sources grouped as "Supporta", "Contraddice", "Contesto";
- source cards show publisher, date, source type and a concise extracted observation;
- a small provenance trail: fetched -> observation -> verification;
- bottom actions "Metti in attesa" and "Invia a revisione"; publication is visually a
  later separate step, not a primary green button.

Across the top or under the job title, show a restrained progress sequence:
Acquisizione ✓  Trascrizione ✓  Claim 12/18  Fonti 7/12  Verifica 4/12  Revisione 1/12.

The screen should clearly suggest meaningful live animations: new transcript lines,
claim cards appearing, source receipts arriving, states advancing. Avoid fake scanning
lasers, glowing AI or magical verdict effects. The overall result should look like the
best professional verification workspace in the world: dense, calm, understandable and
auditable.
