# Image prompt — Direction B: Evidence Record Explorer

Generate a high-fidelity desktop web application mockup, 16:10 landscape, for **Agli
Atti**, an Italian fact-checking platform with long-term memory of public statements.

This direction should feel more like an original information product than a news site,
while remaining warm, readable and consumer-friendly. Minimal neutral interface, precise
typography, subtle depth, fine divider lines, compact evidence chips, one restrained
accent color. Absolutely avoid legal-document aesthetics, court imagery, truth meters,
scores, gamification, political party colors and generic chatbot UI.

Design a public **Explore** screen. Header: Dichiarazioni Pubbliche; Fact-check; Esplora active; Persone;
Temi; Metodo; search.

At top, a very strong universal search experience: "Cerca una dichiarazione, una persona,
un tema o una fonte". Directly below, lightweight filter chips: periodo, tema, fonte,
tipo di verifica, stato.

The main area should have three coordinated layers:

1. a clean list of checked claims on the left/center, each showing original wording,
   date, source and a subtle assessment state;
2. a slim chronological rail/timeline visually connecting repeated or related statements
   over time;
3. an evidence detail panel on the right for the selected claim, showing 3–4 source cards
   with publisher, date, source type, short structured observation and icons for support,
   contradiction or context.

Show one selected relationship between an older and newer statement as
"Possibile cambio di posizione — relazione revisionata", with two dates and a button
"Confronta". Do not imply deception or intent.

The visual signature should be chronology + evidence provenance, not a graph full of
nodes. It should feel like a beautiful public record explorer that a normal reader can
understand immediately, not a research database or government archive. Exceptional UX,
high information clarity, sophisticated but restrained product design.
