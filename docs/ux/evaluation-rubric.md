# Dichiarazioni Pubbliche Visual Concept Evaluation Rubric

Score each generated concept from 1 to 5 on every criterion. Do not pick a winner from
"looks cool" alone.

## Public-facing criteria

| Criterion | Question |
|---|---|
| Instant comprehension | In five seconds, is this obviously a fact-checking product? |
| Not legalistic | Does it avoid looking like a court, law firm, PA portal or document archive? |
| Trust without stiffness | Does it feel rigorous without feeling bureaucratic? |
| Claim-first hierarchy | Is the checked statement more prominent than generic article chrome? |
| Evidence legibility | Can users discover sources/context with one obvious action? |
| Neutrality | Does the interface avoid partisan/ideological visual coding and person scoring? |
| Uncertainty | Do pending/context/unresolved states look deliberate and understandable? |
| Memory | Is there a recognizable sense of chronology/history/comparison? |
| Scanability | Can a user compare several fact-checks quickly? |
| Mobile potential | Can the hierarchy collapse naturally to phone width? |

## Studio criteria

| Criterion | Question |
|---|---|
| Input clarity | Is it obvious how to analyze URL/text/video/podcast/file? |
| Live orientation | Can the operator immediately see what stage the system is in? |
| Transcript/claim linkage | Can the operator jump from claim to exact media moment? |
| Evidence triage | Are support/contradict/context sources easy to inspect without visual overload? |
| Publication separation | Is analysis visibly separate from approval/publication? |
| Density | Does the wide screen earn its complexity rather than becoming a dashboard wall? |
| Motion opportunity | Are there clear places for meaningful progress animations? |
| Error/blocked state | Would provider failure or insufficient evidence fit naturally into the UI? |

## Brand criteria

| Criterion | Question |
|---|---|
| Distinctiveness | Would this be recognizable without the logo? |
| Contemporary | Does it feel current without looking like a generic AI startup? |
| Longevity | Could this survive five years without looking trend-chasing? |
| Two-density system | Could the same visual language support both Public and Studio? |

## Automatic rejection conditions

Reject a concept regardless of score if it relies on any of these:

- courtroom/gavel/scales/parchment/seal aesthetics;
- truth meters, grades or person-level reliability scores;
- red/green as the only way to understand verdict state;
- party colors as structural navigation;
- a giant chatbot conversation as the primary product UI;
- fake terminal/code aesthetics to signal "AI";
- animated research steps that suggest work occurred when no persisted step exists;
- public raw transcript/evidence dumps;
- publishing action visually conflated with analysis completion.
