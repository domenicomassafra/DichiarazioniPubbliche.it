## Master direction

Design the full **Dichiarazioni Pubbliche** product as a contemporary Italian information system with
the confidence of Olivetti-era graphic design but **without retro cosplay**.

This is not a vintage website. Borrow the attitude: asymmetric grids, typography as
structure, deliberate geometry, limited signal colors and cultural sophistication applied
to technical information.

### Visual thesis

An evidence ledger built by an excellent Milanese product/editorial design studio: sharp,
precise, asymmetric, memorable, but always usable.

### Typography

- primary grotesk: **Archivo / Neue-Haas-like grotesk**, strong weights for claims and
  navigation;
- long reading: **Source Serif 4** only where paragraphs need it;
- system/timestamps/data: **IBM Plex Mono**;
- large dates, section numerals and timestamps may become compositional anchors;
- avoid fashionable oversized ultra-light type.

### Palette

- bone `#F2EBDD` / chalk `#F7F4EA`;
- ink `#111111`;
- vermilion `#D9442F`;
- ultramarine `#2450A4`;
- muted teal `#2B8777`;
- ochre `#C59B2B`;
- use one dominant signal color per screen, not all accents simultaneously.

### Grid/geometry

- visible 12-column discipline, asymmetric compositions;
- sharp corners; no universal radius;
- hairlines and blocks; no soft shadows;
- small square/circle markers can encode states/time when accompanied by text;
- whitespace is geometric, not merely generous.

### Signature interaction

The **ledger strip**: a narrow numbered/date rail organizes claim, source, evidence and
history. It may run vertically on reading pages and horizontally in ContentAudit. It uses
simple marks, not a node graph.

### Status

Use tiny geometric signal + written state, for example a 6px ochre square followed by
`Imprecisa`. No rounded pills. Never apply state colors to a person's identity.

### Imagery

Source photography/video is cropped confidently and integrated with the grid. No stock,
no sepia, no paper grain, no typewriters, no vintage office furniture, no mid-century
illustration mimicry.

### Motion

Short geometric transitions: ledger marker moves, selected column/row snaps into focus,
timeline cursor advances. No bouncing, glow or parallax.

### Hard rejects

No retro poster recreation. No Bauhaus costume. No fake print texture. No generic SaaS
cards. No dashboard KPI tiles. No gradients. No pill overload. No giant politician
portrait. No case-study packaging around the UI.

Use neutral/fictional illustrative public-claim content, not invented allegations about a
real person.

## FACT-CHECK DESKTOP

Generate a full-bleed desktop screenshot of one **Dichiarazioni Pubbliche Fact-check** in Italian
Modernist Ledger style.

Use a bold asymmetric grid. A narrow vertical ledger strip at left lists the record steps
as numbers/dates: `01 dichiarazione`, `02 verifica`, `03 fonti`, `04 contesto`, but do not
make it a wizard. Main claim spans a large central block: original wording in strong
grotesk or restrained serif at 42–56px equivalent, with source/person/date beneath.

Finding state is a small ochre/vermilion geometric mark plus written label, never a pill.
One-sentence answer appears as a strong black text block aligned to a key line. `Perché`
follows in a comfortable reading column. Key data can use a minimalist ruled comparison,
with big tabular numbers integrated into the grid.

Sources appear as a numbered ledger list with publisher, document name, reference date
and external-link mark. The selected source number visually corresponds to a small source
marker in the rationale. Media moment is one sharp rectangular frame. Corrections/history
use dated rows lower down.

No soft card boxes, no left app sidebar, no decorative retro shapes.
