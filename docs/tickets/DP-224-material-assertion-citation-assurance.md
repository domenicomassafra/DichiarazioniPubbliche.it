# DP-224 — Material-assertion citation assurance

Status: IN PROGRESS
Milestone: M2 — Live pipeline readiness and source coverage
Depends on: DP-215, DP-210; coordinate with DP-216 and DP-308

## Problem

The current Finding/public projection proves that approved Evidence and Observations are
linked to the Finding. It does not yet prove that every material assertion in the public
rationale/explanation is bound to exact approved evidence/observation support.

## Outcome

Port Claim Polygraph's citation-assurance principle into the project domain: public
explanatory assertions become structured, versioned objects with explicit support refs and
a deterministic fail-closed audit. An unsupported material assertion blocks publication.

## Requirements

- Introduce a bounded Finding Assertion or equivalent structure with stable ID, assertion
  text/hash, assertion type, materiality, evidence/observation/passage refs and version.
- Assertion text generated by a model is never evidence; cited refs must already be
  approved and belong to the same verification/finding packet.
- Exact source/passages remain private unless DP-305 permits an excerpt; the assurance
  checker operates on private provenance.
- SUPPORT, CONTRADICT, CONTEXT, LIMITATION and UPDATE relations remain explicit;
  contradictory evidence cannot be cited as support by mistake.
- Assertion support becomes stale when the cited capture/evidence/observation changes.
- Public projection re-runs the assurance gate under DP-308.

## Acceptance criteria

- [x] Every material public assertion has at least one compatible approved support ref in
  the pure assurance contract.
- [x] Unknown or unapproved evidence/observation refs block the assertion.
- [x] Evidence outside the supplied Finding packet cannot satisfy the assertion.
- [x] A contradiction/context-only ref cannot silently satisfy a SUPPORT requirement.
- [x] Tampering with assertion text stales the binding.
- [x] Non-material navigation/method copy is not forced into the Finding assertion ledger.
- [ ] DP-223 includes unsupported/incorrect-citation adversarial cases.
- [x] Finding creation now persists one versioned RATIONALE_MATERIAL assertion plus SUPPORT
  citation bindings to the exact evidence/approved observation IDs of the same verification
  run.
- [x] Public SQL projection requires the exact current rationale assertion and rejects any
  material assertion without a compatible Finding evidence + approved verification
  observation citation.
- [x] New assertion/citation tables are included in backup/restore load-bearing inventory.
- [ ] Extend citation bindings to exact Passage/source hashes where the Finding assertion
  depends on unstructured evidence rather than structured observations.
- [ ] Run migration/replay and MiniPC database proof before DONE.

## Completion receipt

Local assurance contract, persistent rationale assertion/citation schema, transactional
Finding insertion, projection-time fail-closed gate and backup/restore inventory added
2026-10-05. Passage/source-hash enrichment and real PostgreSQL/MiniPC proof remain open.
