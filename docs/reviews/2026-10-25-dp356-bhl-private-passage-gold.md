# DP-238 / #356 — source-pinned independent OCR gold, private consumer (2026-10-25)

## Source and permissions checked for this technical benchmark

The source is an **authentic scanned page** of *Birds of Great Britain and
Ireland*, vol. 2 (1908), BHL PageID 8992356, holding institution American
Museum of Natural History Library, scan 2008-09-18. BHL's
[item catalog](https://www.biodiversitylibrary.org/bibliography/8651) lists the volume
`NOT_IN_COPYRIGHT`; the
[BHL reuse policy](https://about.biodiversitylibrary.org/help/copyright-and-reuse/) permits reuse
for that category. Both were checked 2026-10-25. This is an institutional
library scan and a **technical OCR benchmark**, not an Italian official,
judicial or political statement or a new editorial source.

The [FineBooks IMPACT-BHL dataset](https://huggingface.co/datasets/finebooks/bhl-impact-gt) attributes the
expert-corrected PAGE XML to IMPACT Centre of Competence and Biodiversity
Heritage Library (2012), under **CC BY 3.0**. The historical gold was produced
before the project's Tesseract run; its human-corrected OCR is independently
authored but does not prove double-key transcription of this specific page.
Owner [decision A](https://github.com/domenicomassafra/DichiarazioniPubbliche.it/issues/102#issuecomment-6300419786)
accepts this **external technical reference with HOLD**. FETCH, temporary
private storage and local OCR are within this narrow source-specific use.
Public excerpts, editorial quote authority and a `CURRENT` operational
rights-registry record have **not** been established by this benchmark.
No new rights were inferred from download success or a synthetic fixture.

The CLI `tools/dp356_bhl_private_gold.py` refuses changed source, gold,
dimensions, number of regions or independently transcribed text. Only after
those checks does Pillow build a **local one-page image-only PDF derivative**
for the existing PDF OCR adapter. The original BHL raster is never labeled as
that PDF; PDF bytes and SHA are separately included in each run receipt.
Pillow normally inserts wall-clock PDF creation/modification dates, which
produced different Capture/Passage IDs in the first two consumer runs. A focused
RED regression pinned differing PDF metadata clocks; the fix sets explicit
neutral derivative timestamps (Unix epoch, **not** the source creation time).
GREEN is confirmed by identical IDs on two subsequent native MiniPC runs.
No source image, PAGE XML or full OCR text is committed or published.

## Consumer run and actual result

On Mac Studio, the exact source/gold hashes were re-downloaded and verified.
The existing `tests.test_dp238_source_page_jump` and
`tests.test_dp238_private_capture_postgres` suite passed **8/8** with the
resource guard on 2026-10-25. The independent PAGE XML reconstruction
matched the historical gold SHA exactly. The MiniPC had current copies of
`document_scanned_ocr.py` (`3baf7ab7...`) and
`document_text_extraction.py` (`4afdf846...`), byte-identical to Studio.

On MiniPC, the installed CLI ran the real Tesseract **5.5.0** / Poppler OCR
consumer against the pinned BHL scan and independently reconstructed gold.
It saved the PDF to a private `CaptureBodyStore`, reopened it by exact SHA,
reran the **native** OCR parser through `document_passages_from_capture`,
verified the generated `Page`/`Passage` text positions and hashes, and
rejected a one-byte-changed source before parser replay. Source-use remains
the narrow technical benchmark; the in-memory Capture is **not** a persisted
PostgreSQL Capture/Passage and does not confer operational authorizations.

CER and WER are whole-page Levenshtein edit distances divided by the lengths
of normalized expert-gold characters and tokens, respectively. Reading order
is unreviewed and may affect both; the independent missing number `81` already
requires HOLD. This is the actual independent-gold *failure outcome*, not a
quality acceptance or a generated gold passed off as original transcription.
The existing negative tests cover held rights and altered source navigation.

For private replay (the original raster and XML must first be obtained from
the pinned URLs and checked against the hashes above):

```sh
PYTHONDONTWRITEBYTECODE=1 python3 tools/dp356_bhl_private_gold.py \
  --scan /path/to/scan.webp --gold-xml /path/to/gold.xml \
  --private-store /path/to/private-store --receipt /path/to/receipt.json
```

This canary and the reviewed metadata are safe to merge while source-use
`CURRENT`, PostgreSQL Passage persistence and editorial/judicial gold remain
separate gates. A public source jump for the locally derived PDF is not
asserted. No DB, live projection, paid provider, public route or release was
changed by the canary.
