## Adapter boundary

`capture_monolith_adapter.MonolithArchiveAdapter` implements the existing `capture_pipeline.ArchiveAdapter` protocol. Construct it explicitly with the private `CaptureBodyStore.root`, an absolute executable path, exact SHA-256, and the **same** live `SourceFamilyUseGuard` supplied to `capture_content(archive_adapter=..., source_use_guard=...)`. By default `archive_adapter=None`: no extra file, process, network request, source-use permission or change in publication. The source's `content_policy.archive_enabled` can still disable this optional stage.

The pipeline checks `FETCH`, `STORE_BODY`, `PARSE_TEXT` and separately `ARCHIVE` before acquisition, again before archiving, and the adapter revalidates `ARCHIVE` against the current rights record before running and after the process completes. An invalid/missing/replaced/version-mismatched binary, revoked source use, non-HTML capture, held/purged body, malformed/oversized result, failing subprocess or timeout fails closed without snapshot success.

Monolith is invoked with the **approved captured HTML from stdin**, `-b` set to the original capture URL only for relative-address resolution, never the original URL as a fetch target. `-a -c -f -F -i -j -v` drop remote audio, CSS, frames, fonts, images, JavaScript and video; `-I -M` isolates the saved document and removes tool-generated source headers; `-d no-assets.invalid` restricts asset domains. No cookies or authentication are forwarded. Network proxies are pointed at an unusable loopback port; this adapter does not provide remote asset downloads, media archiving, an SSRF-capable URL fetch or any publication right. It is intentionally a **document-only** snapshot, so visual resources may be absent. `capture_pipeline` independently rejects unsafe literal source URLs, and the source-use guard requires the observed final URL to match its reviewed subject (including redirects). Any future full-resource archiving needs a separately approved, controlled network fetcher and rights review.

Inputs are bounded at 2 MiB; outputs at 4 MiB and 30 seconds (default 10s). The subprocess uses a fixed argv without shell, a short sanitized environment, a disposable working directory, and an OS file-size limit. Output and intermediate data remain under a mode-`0700` private storage root; accepted immutable `archives/<digest-prefix>/<sha256>.html` files are mode `0600`. A successful private receipt carries `snapshot_kind=PRIVATE_HTML`, relative `snapshot_ref`, `snapshot_sha256`, `snapshot_bytes`, `source_capture_id`, `original_url_sha256`, pinned adapter/binary identity and `publication_state=HOLD`. `snapshot_ref` is **not** an `archive_url` and must never appear in a public projection. The authoritative source URL stays on `ContentCaptureRecord.final_url`; the snapshot is a derived private artifact.

Existing `REQUESTED`, `PENDING`, `SUCCEEDED` / `FAILED` capture lifecycle events and SQL receipts are reused. A successful existing capture is replayed without restarting Monolith; a previously failed archive can be retried with current source approval, preserving content provenance. Incomplete pending operations remain visible as pending for operator reconciliation, never silently promoted. Neither successful capture nor private archiving authorizes source-use on real media, verification or publication.

## Acceptance evidence

Offline tests: `PYTHONDONTWRITEBYTECODE=1 PYTHONPATH=poc python3 -m unittest discover -s tests -p test_capture_monolith_adapter.py -v`. Synthetic fixtures use a controlled CLI stub with a pinned digest. Coverage includes denied rights before fetching, revocation during subprocess, unsafe target URLs, missing/modified executable, process failure, invalid output, timeout, output cap, snapshot hash/permissions, request/pending/completion receipts, and failed/successful replay. Run on the MiniPC in an **isolated temporary checkout**; set `DP_MONOLITH_TEST_BINARY=/absolute/pinned/monolith` to run the conditional real-CLI integration test on synthetic HTML only. Real source acquisition and publication remain gated by independent owner authorization.
