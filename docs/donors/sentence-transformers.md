## Adapter and invariants

The project adopts upstream `SentenceTransformer` via `private_semantic_matching.run_private_semantic_matching`, which takes the native `candidate_matching.MatchingInput` and delegates pair classification to the existing `candidate_matching.rank_candidate_matches` / `proposition_clustering.classify_proposition_pair`. Exact normalization, lexical matching, `matching_input_fingerprint`, replay, existing run IDs, cluster memberships, evidence, Person semantics, persisted dispositions, verified findings and the public projection remain authoritative. A hint is only `match_class=UNCERTAIN`, `disposition=HOLD`, `method=MODEL_SUGGESTION`, with no cluster ID, publication right or vector persistence. The adapter never modifies or inserts a database row. It only scores the bounded set of targets already retrieved through the native matching pool; no search or vector infrastructure is introduced.

Opt-in prerequisites on MiniPC hostname `udodo` (Linux), in an **isolated private backend process**:

1. An operator separately reviews the exact model repository revision (40-hex commit), full model license and provenance, and makes a local snapshot with safetensors weights. Reject a model whose license or redistributability is unresolved.
2. Create an operator-private JSON receipt outside the Git repository with the following structure (replace all placeholders with separately verified values and SHA-256 digests):

```json
{
  "model_id": "owner/model-name",
  "revision": "0123456789012345678901234567890123456789",
  "model_dir": "/home/udodo/.local/share/dichiarazioni-pubbliche/private-model",
  "license_spdx": "Apache-2.0",
  "license_source_url": "https://example.org/actual-model-license-at-pinned-revision",
  "license_reviewed": true,
  "files": {
    "LICENSE": "<actual 64-character SHA-256>",
    "model.safetensors": "<actual 64-character SHA-256>",
    "config.json": "<actual 64-character SHA-256>"
  }
}
```

The sample illustrates the schema; the selected IBM model is identified separately above. Include **every** file in the on-disk inference subset (e.g. `modules.json`, tokenizer and pooling files). Symlinks, undocumented extra files, pickle weights and a mismatch of any file hash are rejected. The `LICENSE` file must be included and hashed, including when the upstream model repository supplies its license through a separately pinned source repository. An operator sets `license_reviewed=true` only after separately verifying that the declared SPDX license applies to **that** exact model revision. Allowlisted SPDX identifiers are Apache-2.0, MIT and BSD 2/3-clause.

3. Install the opt-in `semantic-candidates` extra in a MiniPC-only environment, after checking its transitive package inventory, and set `DP_PRIVATE_SEMANTIC_ENABLED=1` and `DP_SEMANTIC_MODEL_RECEIPT=/absolute/path/private-receipt.json`. Invoke `run_private_semantic_matching(candidate, targets)` only from private operations. The library must be installed at exactly `6.1.0`. The default install/worker/browser/CI never activates it. No cloud API or Hugging Face Hub call is made by the adapter; `local_files_only=True`, `trust_remote_code=False`, `HF_HUB_OFFLINE=1` and `TRANSFORMERS_OFFLINE=1` apply.

Budget: at most 32 existing targets, 400 characters per text, 128 local model files, 384 MiB of fully hashed model files, safetensors only, 1024 output dimensions, 128 input tokens, CPU only, 1 compute thread and batch size 8. The child process is limited to 4 GiB address space and 40 CPU seconds; the caller waits at most 45 wall seconds. The child receives only a restricted environment (no service/API credentials), and rejects direct invocation without opt-in; corrupted/nonfinite/unnormalized vectors yield no hints. Missing flag, host, package, receipt, weights, license review, matching SHA, compatible model or child output returns an explicit blocked or disabled result with **zero** hints. The deterministic path is usable independently.

## Test and benchmark receipt

`tests.test_private_semantic_matching` contains synthetic vectors for Italian paraphrases and adversarial negation, quotations, homonyms, numeric values, claim type, period and republication. The vectors deliberately grant maximum similarity on negative examples; the deterministic gates still refuse them. The 2026-10-23 live model probe found a pre-existing exception in the **native** lexical ranker: negation and added quotation marks could yield `PROPOSE_CLUSTER`. Its new regression went RED (4/4 negative cases failed: negation, quotation, identity, numeric scope), then GREEN by sharing deterministic conflict features with the semantic adapter and bumping `DISPOSITION_POLICY_VERSION` to v3. Original exact-match behavior is still covered by `tests.test_candidate_matching` and `tests.test_proposition_clustering`.

For a real Italian source, the private comparison uses the European Commission's ["Legge sull'IA"](https://digital-strategy.ec.europa.eu/it/policies/regulatory-framework-ai), specifically the exact editorial sentence "L'obiettivo delle norme è promuovere un'IA affidabile in Europa." (© Unione europea; [website reuse license CC BY 4.0](https://digital-strategy.ec.europa.eu/it/pages/legal-notice), attribution and changes identified). Its presence was verified in the live HTML on 2026-10-23. The paraphrase, negation, quotation, entity conflict, different period and type, and republication candidates are *test variations authored for this comparison*, never other source quotations, independent evidence or public Statements. No personal data, third-party content, database write or claim publication is involved. The sample is a rights-checked real **source excerpt**; the modified variants are deliberately synthetic.

**Private real-weight MiniPC probe (2026-10-23, corrected adapter):** `DP_PRIVATE_SEMANTIC_ENABLED=1 PYTHONPATH=/tmp/dp157-verification/poc /home/udodo/.local/share/dichiarazioni-pubbliche/private/semantic-157/venv/bin/python` and `run_private_semantic_matching` with the receipt above produced `HOLD / PRIVATE_REVIEW_ONLY`: semantic hints for paraphrase and explicit republication (2/7 target variants), both `UNCERTAIN`, `HOLD`, with cosine `0.867989`; negative cases (negation, quotation, homonym/identity, different period and claim type) produced no semantic hints (0/5).
