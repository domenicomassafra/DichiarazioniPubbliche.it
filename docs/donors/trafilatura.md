# Trafilatura donor provenance — private HTML captures (issue #168)

- Upstream project: https://github.com/adbar/trafilatura
- Release used: `v2.3.1`, published 2026-10-06; immutable tag commit [`e2f85c965662c7df26b73290ef175b2c2a5fdca6`](https://github.com/adbar/trafilatura/commit/e2f85c965662c7df26b73290ef175b2c2a5fdca6). PyPI optional extra: `trafilatura==2.3.1` (`pip install '.[capture-html]'`).
- License: **Apache-2.0**. Source [`LICENSE`](https://github.com/adbar/trafilatura/blob/v2.3.1/LICENSE); keep its copyright, LICENSE and any notices supplied with the installed distribution. No upstream source, model or dataset is copied into this repository. Dependency license notices remain in the separately installed wheel and its transitive distributions.
- API reused: [`trafilatura.extract`](https://trafilatura.readthedocs.io/en/latest/corefunctions.html) with `output_format="txt"`, `include_comments=False`, `include_tables=False`, `favor_precision=True`. It receives already observed, decoded HTML only; it has no URL/network acquisition authority. Metadata identity stays with `extract_source_metadata` and its existing HTTPS filtering.
- Local adapter: `capture_trafilatura_adapter.TrafilaturaHTMLParser` implements `capture_pipeline.ParserAdapter`, selected by passing `parser=TrafilaturaHTMLParser()` to `capture_content`. The default pipeline still uses `StdlibVisibleTextParser` and `dependencies=[]` stays unchanged. The adapter accepts **only 2.3.1** to maintain deterministic replay; missing/mismatched/import-failing/exception-raising installations fall back to `stdlib-visible-text-v1`. Empty extraction yields `PARSER_EMPTY_TEXT` / HOLD, even if navigation chrome is visible.
- Parser receipts: successful parses use `TRAFILATURA_HTML` / `trafilatura-2.3.1-dp1`. Fallback receipts use the actual stdlib parser name/version and `source_metadata.html_extraction.fallback_reason` when metadata policy permits. The existing capture retains original response bytes SHA-256, source URL/observed-at/rights and canonical passage spans/text SHA; `PARSE_SUCCEEDED` and `PARSE_FAILED` contain the effective parser method/version. No auto-publishing or external fetch is added.
- Local-only fixtures: fictional Italian article and institutional HTML in `tests/test_capture_trafilatura_adapter.py`; no third-party content downloaded, indexed or licensed as facts. Unit tests use a deterministic fake extractor; integration tests exercise real 2.3.1 when installed, otherwise skip. This is extraction validation, not source-use approval.
- Overlap: [#156](https://github.com/domenicomassafra/DichiarazioniPubbliche.it/issues/156) requests the same optional private HTML extraction. Coordination/closure of #156 belongs to the prime; this PR only implements #168.
