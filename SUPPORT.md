# Support

Dichiarazioni Pubbliche is currently a pre-1.0 open-source project.

Use a bug report for reproducible software defects and a feature request for product or
developer-experience proposals. Questions about the meaning of a published finding,
corrections, or rights of reply will get a dedicated public process before launch and
should not be treated as ordinary software support tickets.

Security vulnerabilities must follow `SECURITY.md`.

There is currently no SLA, paid support commitment, or guaranteed response time.
